一、系统定位

LJM v2.0 面向 Agent Memory Leaderboard（AML）文本记忆赛道学术榜参评，是一套以 MemOS 为架构基线、深度融合 Cognee、Mem0、MemPalace、Vectorize Hindsight 四类开源记忆系统核心优势的长期记忆服务。系统覆盖长对话、跨会话历史、个性化偏好、规则执行、时序事件与连续叙事等场景，实现「写入（Add）→ 检索（Search）→ 治理」全链路，严格对齐 AML 官方 Add/Search 契约。

二、Docker 启动方式

在仓库根目录执行以下命令即可一键构建并启动服务，服务监听 0.0.0.0:8000：

    docker compose up --build

模型权重（BAAI/bge-small-en-v1.5）在镜像构建阶段自动在线下载，Git 仓库内不含任何二进制权重文件。本地无 Docker 环境时，可执行：

    pip install -r requirements.txt
    uvicorn app.main:app --host 0.0.0.0 --port 8000

三、接口封装位置

- 接口层：app/main.py（/health、/v1/memories/add、/v1/memories/search）
- 契约模型：app/schemas.py
- 写入链路：app/ingest/（chunker 分块、extractor 抽取、scoring 评分、dedup 去重）
- 检索链路：app/retrieval/（hybrid 多路融合、graph_recall 图谱召回、rank 重排）
- 记忆治理：app/governance/（conflict 冲突检测、retention 保留策略）
- 存储层：app/storage/（SQLite 源存储 + 向量索引）

四、原始方法披露

1. 基线系统 MemOS（https://github.com/MemTensor/MemOS）：分层记忆架构与时序事件处理基座；
2. Cognee（https://github.com/topoteretes/cognee）：知识图谱实体关系抽取、多跳推理召回；
3. Mem0（https://github.com/mem0ai/mem0）：事实自动抽取、用户偏好记忆、重要性评分机制；
4. MemPalace（https://github.com/MemPalace/mempalace）：分层存储结构、长程记忆锚定；
5. Vectorize Hindsight（https://github.com/vectorize-io/hindsight）：事后去重降噪、记忆治理机制。

五、方法改动说明

1. 混合检索策略优化：稠密向量 + BM25 + 实体图谱三路召回，Reciprocal-Rank Fusion 融合后按「语义相似度 + 时序新鲜度 + 记忆重要性」综合重排；
2. 冲突检测修正：偏好与规则类记忆改为可累加，仅互斥属性（地点/职业/姓名）触发版本取代，避免误删互补记忆；
3. 认识论安全门新增：相关性阈值 + 关键词 + 图谱三重信号门控，无匹配严格返回空数组；
4. API 契约对齐 AML 官方规范：字段、类型、嵌套结构、同步语义、空结果行为逐条对齐；
5. 嵌入编码修正：为 bge 模型补上 query 指令前缀，并拆分返回内容与索引文本以消除时间戳前缀污染；
6. 性能优化：索引可重建、单锁串行化、嵌入模型启动预热，Add/Search 达到 Fast 档位。

六、合规声明

本系统严格遵循 AML 参赛核心规则：Search 接口仅返回原始记忆证据，不生成最终答案、不拼接结论、不伪造记忆内容；所有检索严格按 user_id 隔离，禁止跨用户检索；未硬编码任何评测答案，未泄露评测数据，未操纵评分结果；所有复用的开源方法与代码均在 README 与文档中明确标注原始作者、仓库来源与改动点；所有模型与数据集使用均遵循上游开源协议。
